# 🏥 ARAGOG Medical AI Assistant

**Advanced Retrieval-Augmented Generation for Omniscient Guidance**

A production-grade medical question-answering system with React frontend and FastAPI backend, powered by RAG and Mixture of Experts architecture.

## 🎯 Features

- 🎨 **Modern React UI** - Beautiful, responsive interface
- 🤖 **AI-Powered** - Advanced RAG + MoE architecture  
- 💬 **Real-time Chat** - Conversational medical assistance
- 🔐 **Secure Auth** - User authentication & session management
- 📊 **15+ Medical Domains** - Comprehensive medical knowledge

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: FastAPI + Python
- **AI**: PyTorch + Transformers + FAISS
- **Database**: SQLAlchemy
